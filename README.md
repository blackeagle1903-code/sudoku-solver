# sudoku-solver

sudoku_solver.py is a lightweight, dependency-free Python script that automatically solves 9x9 Sudoku puzzles using the Backtracking algorithm. The code consists of the is_valid function for cell validation, solve_sudoku for recursive solving, and print_board for clean console output. To solve your own puzzle, simply update the sudoku_board variable at the bottom of the script, using 0 for empty cells.
